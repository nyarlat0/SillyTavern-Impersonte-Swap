# Impersonate Swap

Расширение SillyTavern для обмена ролями при **Impersonate** (кнопка или `/impersonate`). Поддерживает Chat Completion и Text Completion, включая Instruct.

## Использование

Папка уже расположена в `public/scripts/extensions/third-party/impersonate-swap`. Перезагрузите страницу SillyTavern. В настройках расширений появится **Impersonate Swap**.

Все переключатели включены по умолчанию:

- **Включить Impersonate Swap** — общий выключатель.
- **Менять user ↔ assistant в истории** — прежние сообщения пользователя становятся ответами модели, а сообщения персонажа — пользовательскими ходами. Порядок, имена авторов и тексты сохраняются. Системные сообщения, Narrator и записи вызовов инструментов исключены.
- **Менять {{char}} ↔ {{user}} в System Prompt** — в Text Completion применяется к System Prompt; в Chat Completion — к Main Prompt. Учитываются переопределения system prompt из карточки и метаданных чата.
- **Менять {{char}} ↔ {{user}} в Context Template** — Story String, Chat Start и Example Separator для Text Completion. Chat Completion не использует этот шаблон.

Обмен выполняется только в промпте Impersonate. Сохранённая история не переписывается, а результат, как обычно, появляется в поле ввода пользователя. Обычные ответы персонажа не меняются.

При обмене истории Chat Completion не получает штатную дополнительную инструкцию Impersonate. Instruct получает финальный маркер ответа assistant с именем пользователя. Для обычного Text Completion остаются именные реплики и завершающее имя пользователя: отдельных API-ролей в этом формате нет.

Меняются именно макросы `{{char}}` и `{{user}}`, а не буквальные имена. Описания персонажа и персоны, World Info, примеры диалогов, тексты сообщений, Author's Note, Post-History Instructions и остальные блоки Prompt Manager не подвергаются такой замене. Сами описания персонажа и персоны местами не переставляются.

## Реализация и проверка

Используются штатный generation interceptor и события SillyTavern. Interceptor меняет копию истории до форматирования и подсчёта токенов. Для Main Prompt локально обёрнут `promptManager.preparePrompt`, поскольку отдельного события перед раскрытием его макросов нет.

Шаблоны временно подменяются на время сборки запроса и восстанавливаются перед отправкой, при остановке, завершении, смене чата и перед следующей генерацией. При JSON-сохранении во время сборки сериализуются исходные шаблоны. Изменения настроек расширения применяются со следующей генерации.

Фоновый dry run оставлен без подмен: SillyTavern пропускает generation interceptors в этом режиме. Проверяйте фактический отправленный промпт, а не предварительную оценку токенов. Расширения, одновременно переписывающие те же шаблоны или роли, могут влиять на результат.

Автоматические проверки без установки зависимостей:

```sh
node --experimental-vm-modules tests/swap.test.mjs
node --check index.js
```

Тесты проверяют обмен ролями без изменения оригинальной истории, границы замены макросов, независимость настроек, Chat Completion / Instruct, восстановление и сериализацию настроек. Интеграционные тесты используют заглушки событий и Prompt Manager, без обращения к модели.

Для ручной проверки создайте диалог `user → assistant`, выполните Impersonate и откройте фактический промпт: роли должны стать `assistant → user`, Main Prompt должен обращаться к персоне через прежний `{{char}}`, а текст сообщений и World Info — остаться прежним. После этого обычная генерация должна использовать исходные роли и шаблоны.
