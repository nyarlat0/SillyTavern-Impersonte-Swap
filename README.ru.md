# Impersonate Swap для SillyTavern

[English](README.md)

Расширение меняет работу **Impersonate**: модель получает ваши предыдущие сообщения как собственные ответы, а реплики персонажа — как входящие сообщения пользователя. Следующий ответ она пишет с вашей стороны диалога.

Дополнительно можно менять местами `{{char}}` и `{{user}}` в выбранных источниках промпта. Для каждого источника есть отдельная галочка. Сохранённая история не переписывается; результат появляется в поле ввода, где его можно проверить и отправить.

## Установка

1. Скопируйте адрес этого GitHub-репозитория из адресной строки браузера.
2. В SillyTavern откройте **Расширения → Установить расширение** (Extensions → Install extension).
3. Вставьте адрес репозитория и установите расширение.
4. Перезагрузите страницу. В настройках расширений появится **Impersonate Swap**.

Extras-сервер, отдельный API-ключ, сборка и установка зависимостей не нужны. Используется ваше текущее подключение к модели.

Для ручной установки клонируйте репозиторий в `public/scripts/extensions/third-party/impersonate-swap` внутри SillyTavern и перезагрузите страницу.

## Использование

1. Откройте чат с персонажем и выберите персону.
2. Включите расширение и выберите области замены макросов.
3. Запустите обычное действие **Impersonate** в SillyTavern.
4. Проверьте текст в поле ввода и отправьте его.

Обычная генерация ответа персонажа работает как прежде. Чтобы вернуть стандартный Impersonate, снимите общий флажок расширения.

## Принцип работы

| Сообщение в истории | Роль при Impersonate |
| --- | --- |
| Ваше сообщение (`user`) | Ответ модели (`assistant`) |
| Ответ персонажа (`assistant`) | Сообщение пользователя (`user`) |
| Ваша следующая реплика | Следующий ответ модели |

Порядок сообщений, имена авторов и тексты сохраняются. Системные сообщения, Narrator и записи вызовов инструментов исключены из обмена ролями.

В выбранных источниках строка:

```text
You are {{char}}. Continue the conversation with {{user}}.
```

обрабатывается как:

```text
You are {{user}}. Continue the conversation with {{char}}.
```

Замена происходит до раскрытия макросов. Буквальные имена не меняются. Описания персонажа и персоны не переставляются между полями.

## Настройки

| Галочка | По умолчанию | Область действия |
| --- | --- | --- |
| Включить Impersonate Swap | Вкл. | Общий выключатель; расширение действует только при Impersonate. |
| История | Вкл. | Роли user ↔ assistant в отправляемой истории. |
| System Prompt | Вкл. | System Prompt в Text Completion или Main Prompt в Chat Completion, включая переопределения из карточки и чата. |
| Context Template | Вкл. | Story String, Chat Start и Example Separator; только Text Completion. |
| Карточка | Выкл. | Описание, личность, примеры диалога и depth prompt. Учитываются переопределение примеров в чате и карточки участников группового чата. |
| Персона | Выкл. | Описание активной персоны, в том числе при вставке на глубине или в Author’s Note. |
| Сценарий | Выкл. | Сценарий карточки и его переопределение в чате; независимо от галочки карточки. |
| Лор / World Info | Выкл. | Содержимое записей глобальных книг, книг персонажа, чата и персоны. Ключи и настройки активации не переписываются. |
| Author’s Note | Выкл. | Заметка чата и включённая заметка персонажа. Вставленные персона и лор подчиняются собственным галочкам. |

Пять дополнительных областей выключены по умолчанию, в том числе после обновления. Изменения настроек применяются со следующей генерации.

Галочка карточки не меняет приветствия, альтернативные приветствия, заметки автора карточки и Post-History Instructions. У System Prompt собственная галочка. Остальные пользовательские блоки Prompt Manager и промпты других расширений не входят в эти области.

## Совместимость и ограничения

- **Chat Completion:** меняются API-роли; при обмене истории убирается стандартная инструкция Impersonate.
- **Text Completion / Instruct:** меняется форматирование истории, а финальный маркер открывает ответ модели с именем пользователя, если шаблон включает имена.
- **Text Completion без Instruct:** отдельных API-ролей нет — используется диалог с именами. Финальная подсказка остаётся именем пользователя, эффект зависит также от system/context template.
- **Предварительный подсчёт токенов:** SillyTavern пропускает generation interceptors в dry run. Расширение тоже пропускает подмену; проверяйте фактически отправленный запрос.
- **Другие расширения:** изменения тех же шаблонов, истории и Author’s Note могут конфликтовать. Подмены настроек временные; изоляция одновременно собираемых промптов не гарантируется.
- **Поведение модели:** буквальные имена и противоречащие инструкции могут влиять на результат. Замена макросов не переписывает смысл описаний.

Расширение зависит от интерфейсов событий генерации, World Info и Prompt Manager в SillyTavern. Минимальная поддерживаемая версия пока не установлена. Автотесты проверяют интеграцию с заглушками; живые запросы ко всем провайдерам не проверялись.

## Решение проблем

**Модель продолжает писать за персонажа.** Проверьте галочку истории и фактический промпт. Найдите буквальные имена или конфликтующие инструкции, в том числе Post-History Instructions. При необходимости включите дополнительные области замены.

**Предпросмотр не изменился.** Это ожидаемо для dry run. Сравните промпт реальной генерации Impersonate.

**Имя в лоре не поменялось.** Меняются только `{{char}}` и `{{user}}` в содержимом активированной записи. Буквальные имена и ключи активации сохраняются.

**Нет панели настроек.** Перезагрузите страницу, проверьте включение расширения в SillyTavern и ошибки загрузки в консоли браузера.

Для сообщения об ошибке откройте Issues этого репозитория. Укажите версию SillyTavern, тип API, Instruct-режим, включённые галочки и минимальный пример промпта без личных данных.

## Обновление и удаление

Используйте менеджер расширений SillyTavern для обновления или удаления, затем перезагрузите страницу. При ручной Git-установке обновление выполняется командой `git pull` в папке расширения.

## Разработка

Из папки расширения, с установленным Node.js:

```sh
node --experimental-vm-modules tests/swap.test.mjs
node --check index.js
node --check core.mjs
```

Тесты проверяют роли и макросы, независимость галочек, групповые карточки, источники лора, составление Author’s Note, восстановление и сериализацию исходных настроек. Флаг VM modules может выдавать предупреждение об экспериментальной функции Node.js.
